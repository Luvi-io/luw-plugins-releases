Luw.ai plugin guides

How to install the Luw.ai plugins and make your first render.

  • SketchUp: install the extension and get your first render
  • Rhino: install the plug-in and get your first render
  • 3ds Max: install the plug-in and get your first render
  • Revit: install the add-in and get your first render
  • Unity: install the package and get your first render
  • Unreal Engine: install the plug-in and get your first render
  • Blender: install the extension and get your first render
