# Luw.ai plugins

Plugins that bring [Luw.ai](https://luw.ai) into SketchUp, Rhino (with Grasshopper), Revit and 3ds Max, by Luvi Technologies. Each one opens Luw.ai in a panel next to your model: your view goes in, and the render comes back into the model.

Get the newest ones on the **[releases page](https://github.com/Luvi-io/luw-plugins-releases/releases/latest)**.

| App | File | Works with |
|---|---|---|
| SketchUp | [`luw_ai-0.1.2.rbz`](https://github.com/Luvi-io/luw-plugins-releases/releases/download/v0.1.2/luw_ai-0.1.2.rbz) | SketchUp 2021.1 and newer, Windows and Mac |
| Rhino + Grasshopper | [`Luw.ai-Rhino-0.1.2.zip`](https://github.com/Luvi-io/luw-plugins-releases/releases/download/v0.1.2/Luw.ai-Rhino-0.1.2.zip) | Rhino 8 and 9, Windows and Mac |
| Revit | [`Luw.ai-Revit-0.1.2.zip`](https://github.com/Luvi-io/luw-plugins-releases/releases/download/v0.1.2/Luw.ai-Revit-0.1.2.zip) | Revit 2024, 2025, 2026 and 2027 |
| 3ds Max | [`Luw.ai-3dsMax-0.1.2.zip`](https://github.com/Luvi-io/luw-plugins-releases/releases/download/v0.1.2/Luw.ai-3dsMax-0.1.2.zip) | 3ds Max 2024, 2025, 2026 and 2027 |
